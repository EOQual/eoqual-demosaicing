# NOTICE — images de test

`lighthouse.tif` / `lighthouse_bayer.tif` (image « lighthouse ») font
partie de la suite d'images de test Kodak :

> Franzen, R. "Kodak Lossless True Color Image Suite."
> http://r0k.us/graphics/kodak/

**Statut** : le site du dépôt indique ces images « released by the
Eastman Kodak Company for unrestricted usage » (mise à disposition par
Eastman Kodak Company pour un usage sans restriction), sans texte de
licence formel ni référence à une déclaration officielle — usage
générique établi comme suite de test de compression/traitement d'image
depuis plusieurs décennies. `lighthouse_bayer.tif` est une mosaïque
Bayer RGGB synthétique dérivée de `lighthouse.tif` par sous-échantillonnage
(voir `examples/`), pas une image capturée par un capteur réel.
